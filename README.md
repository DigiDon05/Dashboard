# 📊 Modern Dashboard UI

A sleek and modern Dashboard UI built using HTML, CSS, and JavaScript.  
It features glassmorphism design, interactive charts, and smooth animations.

---

## 🚀 Features

✨ Glassmorphism UI (blur + transparency)  
✨ Sidebar Navigation  
✨ Responsive Layout  
✨ Dark / Light Mode Toggle 🌙☀️  
✨ Interactive Charts using Chart.js 📊  
✨ Smooth Hover Animations  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox, Animations, Glassmorphism)  
- JavaScript  
- Chart.js  

---

## 📂 Project Structure

📁 modern-dashboard-ui
 ┣ 📄 index.html

## 📊 Chart Integration

const ctx = document.getElementById('myChart');

new Chart(ctx, {
  type: "line",
  data: {
    labels: ["Jan", "Feb", "Mar", "Apr"],
    datasets: [{
      label: "Users Growth",
      data: [200, 400, 600, 800],
      borderColor: "#00FF9C",
      backgroundColor: "rgba(0,255,156,0.2)",
      tension: 0.4
    }]
  }
});
